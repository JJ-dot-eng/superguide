# HELLDIVERS 2 — 스트라타젬 도감

헬다이버즈 2의 스트라타젬 110개를 한국어로 정리한 비공식 팬 사이트입니다. 지원 무기, 궤도, 이글, 센트리·설치물, 배낭, 차량·엑소슈트, 공용·임무로 분류합니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 [로컬 사이트](http://127.0.0.1:4173)를 엽니다. 서버는 이 컴퓨터의 루프백 주소에만 연결되며, 이 명령은 로컬 미리보기만 실행합니다. Sites 배포 설정은 `.openai/hosting.json`에서 관리합니다.

```sh
npm run check
```

검증 명령은 데이터의 필수 항목·단위·중복·범위, 모든 항목의 위키 아이콘 연결과 원본 파일 해시, JavaScript 문법, 정적 파일 응답과 서버의 경로 경계를 확인합니다.

## 사용

- 종류를 고르거나 한국어 이름·영문 이름·장비 코드·용도로 검색합니다. `/` 키로 검색창에 이동합니다.
- 이름은 글자 순서와 띄어쓰기를 무시하고 검색합니다. `격타밀정도궤`, `도밀격`, `도밀타`로 모두 ‘궤도 정밀 타격’을 찾을 수 있습니다. 순서를 섞은 검색은 입력한 글자가 모두 한 이름에 포함될 때 일치합니다. 장비 코드·설명·용도는 기존처럼 단어로 검색할 수 있습니다.
- 이름·영문 이름·별칭에 일치하는 결과를 먼저 표시하고, 설명·장비 코드·용도에만 일치하는 결과는 뒤에 표시합니다. 같은 우선순위 안에서는 기존 도감 순서를 유지합니다.
- 관통 등급을 골라 목록을 좁힐 수 있습니다. 일부 장비는 폭발·전격 등 대표 피해원의 관통이며 상세 설명에 기준을 표시합니다.
- 카드를 열면 짧은 사용법, 주의점, 탄종별 수치와 원문 출처를 확인할 수 있습니다.
- ‘비교 담기’로 2–3개를 선택해 나란히 비교합니다. 분류·검색을 바꿔도 선택이 유지됩니다.
- 모바일에서는 분류 목록을 좌우로 넘길 수 있습니다. 상세 창은 닫기 버튼 또는 Escape로 닫습니다.
- ‘적 대응 계산’에서 적과 지원 무기·발사 모드를 고르면 부위별 처치·출혈·부위 파괴 여부와 이론 탄수를 비교합니다. 지원 무기 상세에서도 바로 이동할 수 있습니다. `#combat` 주소로 계산 화면을 열 수 있습니다.
- 현재 차저, 베히모스 차저, 바일 타이탄, 헐크 스코처, 기본 데바스테이터, 버서커, 지상 오버시어, 하베스터 8종과 주요 지원 무기 12종을 지원합니다. 정밀 계산 미지원 무기는 이유를 표시하며, 이를 처치 불가능으로 분류하지 않습니다.

## 자료 기준

자료 열람일은 2026-09-16입니다. [Helldivers Wiki](https://helldivers.wiki.gg/wiki/Stratagems)의 항목별 통계와 검색 색인에 근거한 정적 자료이며 실시간 패치 동기화는 하지 않습니다. 각 항목에 직접 출처를 제공합니다.

110개 항목의 아이콘은 Helldivers Wiki의 SVG 원본을 내려받아 수정 없이 사용합니다. 위키 정보 상자의 아이콘 연결을 기준으로 하며, 전술 비디오 카메라는 위키에 등록된 전용 아이콘 파일을 사용합니다. 일부 임무용 스트라타젬은 위키에서 같은 아이콘을 공유합니다. 상세 화면에서 각 아이콘의 파일 출처를 열 수 있습니다. 원본 파일 주소·확인 날짜·SHA-256은 `dist/wiki-icons.js`에 기록하며, SVG 내부의 제작자 표기도 보존합니다.

기본 수치를 사용하고 함선 모듈과 행성 효과는 제외합니다. 탄당 피해, 초당 피해, 폭발 반경, 무기 사거리, 자동 표적 획득 거리, 효과 반경을 구분합니다. 복합 화염·가스·파편이나 탄종별 값은 상세 설명에 별도로 적습니다. 직격과 폭발의 단순 합이 실제 체력 감소량을 보장하지 않습니다.

적 대응 계산은 위키 Anatomy 표의 부위 체력·장갑·내구도·폭발 저항·본체 전달 비율·전달 상한·치명 여부와 무기의 내구 피해를 별도로 기록해 사용합니다. 최대 피해로 한 부위를 반복 공격하는 계산 모델이며, 거리 감쇠·각도 변화·다중 부위 폭발·파편·지속 피해는 시뮬레이션하지 않습니다. 관통 수치가 장갑과 같으면 65%를 적용하고 내구도 혼합, 관통·저항, 본체 전달 단계에서 분수를 버립니다. 계산 범위와 소수점 처리 가정은 화면에 공개합니다. 보호막은 제거·우회 여부를 명시해야 계산하며 보호막에 소모한 탄수는 포함하지 않습니다. 장갑 제거의 초과 피해는 다음 층으로 넘기지 않고, 미확인 파괴 후 부위를 반복해서 쏘는 처치 경로는 만들지 않습니다. 출혈 시작 탄수를 즉사 탄수와 구분합니다.

적·무기별 원문 링크와 확인일을 제공하며, 원문 접속이 차단된 경우 위키 본문 통계의 검색 색인을 사용했습니다. 모듈 데이터의 오래된 수치와 현재 본문이 다르면 본문을 우선합니다. 계산 검증은 알려진 약점 사례와 방어막·내구도·장갑 제거·비치명 부위·폭발 전달 경계를 포함합니다.

‘미확인’은 자료를 확보하지 못했거나 출처 내부에 충돌이 있는 값입니다. ‘해당 없음’은 지원 기능에 적용되지 않는 공격 수치입니다. 한국어 이름은 제공된 명칭 목록을 우선하며, 앞의 모델 번호는 이름에 붙이지 않고 장비 코드로 분리합니다. 이름을 바꾸기 전의 표기는 검색 별칭으로 보존하고 영문 이름을 병기합니다. 행사 장비의 사용 가능 여부는 게임 내 허가 상태에 따릅니다. 미출시·만우절·현재 사용할 수 없는 과거 이벤트 전용 항목은 제외했습니다.

## 파일 구조

- `dist/index.html`, `dist/styles.css`, `dist/app.js`: 화면과 상호작용
- `dist/search.js`: 순서에 상관없는 이름 검색과 기존 키워드 검색
- `dist/combat-data.js`, `dist/combat.js`, `dist/combat-ui.js`: 근거가 있는 부위·무기 수치, 피해 계산과 적 대응 화면
- `dist/data.js`: 데이터 조합·분류
- `dist/data-support.js`, `dist/data-offense.js`, `dist/data-equipment.js`, `dist/data-mission.js`: 출처를 포함한 장비 자료
- `dist/wiki-icons.js`: 항목별 위키 아이콘 연결과 원본 출처
- `dist/assets/stratagems/`: 수정하지 않은 위키 SVG 아이콘
- `server.mjs`: 로컬 정적 서버
- `scripts/check.mjs`: 데이터·정적 파일 검증
- `scripts/check-combat.mjs`: 적 대응 계산과 자료 연결 검증
- `.openai/hosting.json`: Sites 연결과 정적 사이트 배포 설정

`dist`는 자동 빌드 부산물이 아니라 직접 관리하는 사이트 원본입니다. Git에 포함합니다. 외부 폰트는 Google Fonts를 사용하며 연결되지 않으면 시스템 폰트로 표시합니다. 스트라타젬 아이콘은 사이트에 함께 포함하여 위키에 다시 접속하지 않아도 표시됩니다.
