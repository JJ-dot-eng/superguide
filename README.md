# HELLDIVERS 2 — 스트라타젬 도감

헬다이버즈 2의 스트라타젬을 한국어로 찾아보고, 피해량·사거리·관통 능력·사용법을 확인할 수 있는 비공식 팬 사이트입니다.

**[사이트 바로가기](https://jj-dot-eng.github.io/superguide/)**

## 사용법

- **찾기:** 종류와 관통 등급으로 목록을 좁히거나 이름·별칭·용도로 검색합니다. 이름은 글자 순서를 섞어도 찾을 수 있습니다. 예: `도밀타` → 궤도 정밀 타격, `반톤` → 이글 500kg 폭탄.
- **상세 보기:** 카드를 누르면 수치, 사용법과 주의점을 확인할 수 있습니다.
- **비교하기:** ‘비교 담기’로 스트라타젬 2~3개를 골라 나란히 비교합니다.
- **적 대응 계산:** 적과 지원 무기·발사 모드를 선택하면 부위별 공격 효과와 필요한 이론 탄수를 확인할 수 있습니다. 일부 적과 무기를 지원합니다.

자료와 아이콘은 [Helldivers Wiki](https://helldivers.wiki.gg/wiki/Stratagems)를 바탕으로 하며, 각 항목에서 출처를 확인할 수 있습니다.
